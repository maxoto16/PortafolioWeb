# Portafolio Web Personal (HTML5 & CSS3)

Este proyecto corresponde a la actividad **AVS.02.02.01 Desarrollo de página HTML y CSS** para la asignatura **Aplicaciones Web** de la Universidad Tecnológica Emiliano Zapata (UTEZ).

## Contenido del Proyecto:
- `index.html`: Estructura semántica completa en HTML5 (Home, Sobre mí, Servicios, Portafolio, Contacto).
- `styles.css`: Hoja de estilos externa con diseño adaptable (Responsive Design) y pseudo-clase `:hover`.

## Instrucciones para ejecutar:
1. Extrae el archivo `.zip`.
2. Haz doble clic en `index.html` para abrir la página en cualquier navegador web moderno (Google Chrome, Firefox, Edge, Safari).
